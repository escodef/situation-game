# Situation Game Backend

Бэкенд для игры ситуации

## Быстрый старт

### Установка зависимостей
```bash
bun install
```

### Запуск
При старте сервер сам автоматически накатит миграции и заполнит базу начальными данными (пак ситуаций + аккаунт админа).
Необходимо будет заполнить .env файл по примеру из .env.example

```bash
# dev
bun run start:dev

# прод
bun run build
bun run start
```

Swagger UI будет доступен по адресу: `http://localhost:3000/openapi`
